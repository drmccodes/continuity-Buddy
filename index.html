1. Import EMIS data

First time only: download the Download the prebuilt EMIS search (.xml), import it in EMIS → Reporting → Population Reporting → Import, then run its patient search and attended-appointments report. These original EMIS search files are provided unchanged. Thanks to Dr Neil Paul for creating and sharing the searches. They have not yet been independently validated in our EMIS installation.

Exact EMIS export steps
  1. Import the downloaded XML into a practice reporting folder (you need suitable EMIS permissions).
  2. Run “Usual GP Continuity 1 - Patients seen in last 12 months”.
  3. Run “Usual GP Continuity 2 - Consultation export”.
  4. Right-click the second report, then View Results → Export → CSV.
  5. Tick Replicate patient details for each item and Replicate Usual GP details. Leave “override hidden patients” unticked unless explicitly authorised.
  6. Choose the CSV below. Do not share identifiable exports in chat or email.

Steps adapted from Dr Neil Paul's EMIS guide. EMIS XML import is documented by CDRC. Your practice's permissions/IT policy determine whether imports are allowed on your NHS PC.

Optional: import the complete registered-patient list

For accurate list sizes, export the companion Download the optional list-sizes search (.xml) from EMIS and load its CSV separately. It should have one row per registered patient, including patient ID and Usual GP.

Data quality and limitations

Appointment/consultation exports cannot establish clinical complexity, patient wishes, actual attendance for every slot type or continuity from non-appointment work. A follow-up registered-list export would be needed for precise whole-practice list balancing.
