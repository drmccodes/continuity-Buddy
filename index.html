Important information governance safeguard

EMIS numbers are still patient identifiers. This app reads CSV files in your browser only, with no network requests or storage. Use only on a practice-approved device and follow local IG policies. Never upload identifiable data to GitHub, chat or external hosting. No automatic changes are made to EMIS.

1

Set up the EMIS searches

You need three reusable search types for each GP. That is approximately 3 × number of GPs, not every possible pair of GPs. All searches must use the same one-year reference window.

A

Current GP list

  1. EMIS Web → Reporting → Population Reporting.
  2. Make a folder named ContinuityBuddy.
  3. Select Add → Patient → Search (menu wording may vary).
  4. In the Patient Details feature, set Usual GP's User is [GP].
  5. Save and run as Owner - [GP].
B

Seen this GP 4+ times

  1. Create a new patient search.
  2. Add a Consultations feature.
  3. Set User Details' User is [GP].
  4. Set Date is after 1 year before search date.
  5. Select # Count and set more than 3 consultations.
  6. Save and run as Seen 4+ - [GP].
C

Not seen by this GP

  1. Create a patient search.
  2. Add a Consultations feature for User Details' User is [GP] and Date is after 1 year before search date.
  3. Set this consultations feature to Exclude.
  4. Save and run as Not seen - [GP].
  5. Check the rule says Exclude Patients with Consultations.
Export each search as an ID-only CSV

In Population Reporting: Add → Patient → List Report → choose your saved search in Results from / Based on → Add → Patient Details → select only EMIS Number (check the exact name in your EMIS version) → Save and Run → right-click report → View Results → Export → CSV. Remove all other fields. Do not substitute NHS number.

Exact menu names for EMIS's internal patient identifier and the ability to export it through List Reports require verification in your practice. If unavailable, do not export NHS numbers as a workaround. The application will not accept them by design.

“Seen 4+” means 4+ recorded consultation entries, not necessarily four conversations. Patient preferences, duty contacts, administrative entries and complexity need manual review.
